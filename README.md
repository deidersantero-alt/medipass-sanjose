# Medipass Urgencias - Portal de Orientación Hospitalaria

Sistema web interactivo diseñado para optimizar el flujo de información y reducir la incertidumbre de los pacientes en salas de urgencias.

## 🚀 Características del Proyecto
- **Clasificación de Triaje:** Módulo dinámico para identificar prioridades de atención médica.
- **Buscador en Tiempo Real:** Filtro de sintomatología básica para orientación del usuario.
- **Contenido Multimedia:** Video guía explicativo y ubicación interactiva en Google Maps.
- **Acceso a Requisitos:** Guía desplegable con la documentación necesaria para la admisión hospitalaria.
- **Módulo de Contacto:** Formulario para atención y orientación al usuario.

## 🛠️ Tecnologías Utilizadas
- HTML5
- CSS3 (Diseño Responsive)
- JavaScript Vanilla
- FontAwesome (Iconografía)
- GitHub Pages (Hosting)
